# Python Learning Lab

A collection of interactive Jupyter notebooks for learning Python fundamentals, from basic syntax to advanced operators and comparisons.

## Contents

### 1. Learn Python (`1.learn-python.ipynb`)
Introduction to Python basics including:
- **Hello World**: Your first Python program
- **Variables**: Working with different data types and values
- **Syntax**: Understanding Python's rules and structure
- **Naming Conventions**: Snake_case, camelCase, and PascalCase
- **Strings**: Creating and working with text
- **F-strings**: Dynamic string formatting with variables
- **Basic Operations**: Math operations and calculations
- **Comments**: Documenting your code

### 2. Functions (`2.functions.ipynb`)
Deep dive into Python functions:
- **Function Basics**: Defining and calling functions
- **Parameters & Arguments**: Single and multiple inputs
- **Return Values**: Getting output from functions
- **Multiple Returns**: Returning multiple values at once
- **Default Parameters**: Optional function arguments
- **Printing vs Returning**: Understanding the difference
- **Function Scope**: Where to declare and call functions

### 3. Scope (`3.scope.ipynb`)
Understanding variable scope in Python:
- **Local vs Global Scope**: Where variables can be accessed
- **Function Scope**: Variable visibility within functions
- **Scope Rules**: How Python resolves variable names

### 4. Unit Tests (`4.unit-tests.ipynb`)
Introduction to testing your Python code:
- **Unit Testing Basics**: What are unit tests and why use them
- **Test Functions**: Creating automated tests for your code
- **Test Cases**: Running multiple test scenarios
- **Pass/Fail Results**: Understanding test outcomes

### 5. Python Operators (`5.python-operators.ipynb`)
Comprehensive guide to Python operators:
- **Numbers & Arithmetic**: Integers, floats, and basic math
- **Floor Division**: Integer division with // operator
- **Exponents**: Power operations with ** operator
- **In-Place Operators**: +=, -=, *=, /= for efficient updates
- **Scientific Notation**: Working with very large/small numbers
- **Logical Operators**: and, or, not for boolean logic
- **Binary Numbers**: Understanding base-2 number system
- **Bitwise Operators**: & and | for bit-level operations
- **Practical Examples**: Permission systems using bitwise operations

### 6. Comparison (`6.comparison.ipynb`)
Boolean logic and conditional statements:
- **Comparison Operators**: <, >, <=, >=, ==, != for comparing values
- **Boolean Evaluations**: How comparisons return True/False
- **If Statements**: Conditional code execution
- **If-Else Chains**: Multiple conditions with elif and else

## Getting Started

1. Open the notebooks in order (start with `1.learn-python.ipynb`)
2. Read through the explanations in markdown cells
3. Run the code cells to see the examples in action
4. Experiment by modifying the code

## Prerequisites

- Python 3.x
- Jupyter Notebook in VS Code with Python extension

## Learning Path

Follow the notebooks in numerical order for a structured learning experience:

1. **Learn Python** - Start with basic syntax and variables
2. **Functions** - Learn to write reusable code
3. **Scope** - Understand variable accessibility
4. **Unit Tests** - Practice testing your code
5. **Python Operators** - Master arithmetic, logical, and bitwise operations
6. **Comparison** - Work with boolean logic and conditional statements

Each notebook builds on concepts from the previous ones, creating a comprehensive foundation in Python programming.
